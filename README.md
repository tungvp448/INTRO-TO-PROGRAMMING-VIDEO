# INTRO-TO-PROGRAMMING-VIDEO

Materials for an **Introduction to Programming** group video assignment covering **Variables and Data Types** and **Lists and Sequences** in Python.

The English lesson script includes content for 18 slides, explanations, code examples with expected outputs, and a student score management example connecting theory to practice. Estimated presentation length: **20–22 minutes**.

The main document is `python_lesson_work/Python_Lesson_Script.docx`. It serves as the foundation for the presentation slides and recorded lesson.
